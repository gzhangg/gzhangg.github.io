Green-Light Security for AI Computing

Toward secure, energy-efficient, and sustainable AI infrastructure.

Green-Light Security reorganizes protection around the common case. Lightweight integrity verification remains continuously in-path, while expensive reliability correction is invoked only when needed. The project combines analytical modeling, simulation, and a Raspberry Pi–ESP32 hardware prototype.

Core idea

Keep inexpensive safeguards always on; move rare, expensive corrective work off the critical path.

Burst-Aware Provisioning for Progressive Protection Under Tail-Latency SLOs

A tail-latency co-design study.

This work studies progressive protection when expensive fallback requests are rare but temporally correlated. A mean-preserving burst model separates how often escalation occurs from how it is distributed in time, connecting analytical queue-tail theory with finite-SLO simulation and system co-design.

Core result

At the same mean escalation probability, severe persistent burstiness can more than double the full-strength capability required to satisfy the same tail-latency SLO.
